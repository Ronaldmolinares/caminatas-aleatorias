# Random Walks Project

## Overview
This project explores the concept of random walks in various dimensions. A random walk is a mathematical formalization of a path consisting of a succession of random steps. It is used in multiple fields such as physics, finance, and computer science.

## Project Structure
- `src/`: Contains the source code for simulating random walks.
- `docs/`: Documentation files explaining the theory and applications of random walks.
- `examples/`: Example scripts demonstrating the usage of the random walk functions.

## Installation
To install the necessary libraries, run the following command:

```bash
pip install -r requirements.txt
```

## Usage
After installation, you can run the simulated random walks as follows:

```bash
python src/random_walk.py
```
